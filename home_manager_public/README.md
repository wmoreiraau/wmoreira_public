# Home Manager

A Flutter app (web-first) for running a shared household: logging home issues,
planning recurring maintenance, getting AI-generated how-tos and shopping
lists, and reviewing monthly spending.

## Features

- **Issues & tasks**: priorities, due dates, reminders, notes, and a Done list.
- **AI "Look up"**: a structured how-to and shopping list for any issue,
  generated by Claude (Haiku 4.5) through a Cloudflare Worker proxy, with a
  plain web-search fallback.
- **Recurrent maintenance**: appliance and chore schedules, with AI maintenance
  plans whose links are validated server-side.
- **Shared households**: Firebase Auth (Google / Apple sign-in), a per-home
  Firestore data model with live sync, invite-code joining, member list and an
  activity feed.
- **Finances**: monthly spending from bank-export CSVs, with a prior-3-month
  average and top categories. The repo ships with fictional sample data in
  `Finances Monitor/Expenses/`.

## Architecture

| Part | Tech |
| --- | --- |
| App | Flutter / Dart (`lib/`) |
| Auth & data | Firebase Auth, Cloud Firestore (`firestore.rules`) |
| AI + privileged writes | Cloudflare Worker in TypeScript (`worker/`) that holds the Anthropic API key and a Firebase service account, so neither ships in the client |
| Finances import | Python + openpyxl desktop tool (`Finances Monitor/`) |

## Running locally

1. Install Flutter and run `flutter pub get`.
2. Create a Firebase project, add a **Web app**, enable Google sign-in, create
   a Firestore database and publish `firestore.rules`.
3. Deploy the Worker (see [`worker/README.md`](worker/README.md)).
4. Copy `dart_defines.example.json` to `dart_defines.json` (gitignored) and fill
   in your Firebase web config and Worker URL.
5. Run:

   ```bash
   flutter run -d chrome --dart-define-from-file=dart_defines.json
   ```

Without `dart_defines.json` the app still starts and shows a "Firebase setup
needed" screen.
